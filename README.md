# Control Room

Personal status board for my apps and projects: status, summary, next steps, a link to the related Claude conversation, and a list of topics to discuss.

Static page, no build step. Open `index.html` in a browser, or host it on GitHub Pages.
Data is saved in the browser (localStorage), so it stays on the device and browser you use.

## Install as an app

Browsers only offer "Install" on a secure address, so open the page from `http://localhost` or from an `https://` host (for example Netlify), not from a file on disk.
Quick local option: run `npx serve` in this folder (or `python -m http.server 8000`), open the address in Chrome or Edge, and use the **Install app** button on the page or the install icon in the address bar. On iPhone, use Share, then Add to Home Screen.
